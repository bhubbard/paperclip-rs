Orchestrate Teams of Autonomous AI Agents

A high-performance, memory-safe Rust control plane for Paperclip. Manage goals, agent hierarchies, budgets, issues, and execution heartbeats with sub-millisecond dispatch.

Quickstart View Repository

⚡ Sub-Millisecond Heartbeats

Dispatches concurrent agent turns, evaluates hierarchical budget caps, and transitions Kanban issue state machines at pure native speeds.

🛡️ Robust Process Supervision

Native process isolation with kill_on_drop, watchdog cancellation tokens, and timeouts for CLI agent runtimes (Claude Code, Codex, AGY, Ollama).

💰 Strict Spend Governance

Enforce HardStop, RequireApproval, and WarnOnly spending rules with human-in-the-loop signoffs to prevent token runaway.

📦 Embedded Single Binary

Compiles into a single standalone static executable (paperclip) containing both the CLI tool and Axum async HTTP control plane.

Quickstart

# Build standalone binary
cargo build --release

# Onboard a virtual AI company
paperclip onboard \
  --name "Apollo AI" \
  --mission "Build the leading autonomous software suite" \
  --budget 100000

# View ASCII Org Chart
paperclip org

# Dispatch agent execution heartbeat
paperclip tick --all
